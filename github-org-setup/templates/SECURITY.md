# Security policy

## Report a vulnerability

Do not open a public issue for a security problem.

Report it privately with GitHub private vulnerability reporting: open the repository's **Security** tab and click
**Report a vulnerability**. If that is not available, send an email to {security_contact}.

Include the affected repository and version, the steps to reproduce, and the impact you expect.

## What to expect

- We confirm that we received your report within {ack_days} working days.
- We send a first assessment within {assess_days} working days.
- We agree a disclosure date with you, and we credit you in the advisory unless you ask us not to.

## Supported versions

Only the latest release of each repository gets security fixes, unless the repository's own SECURITY.md says
otherwise.
